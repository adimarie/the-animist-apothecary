How to generate a token (30 seconds, one time)
  1. Open github.com/settings/tokens/new in a new tab.
  2. Note: The Animist Apothecary editor
  3. Expiration: pick something long like 1 year (you can revoke any time).
  4. Scopes: check repo (top-level checkbox — gives full repo access).
  5. Click Generate token at the bottom. Copy the token (starts with ghp_).
  6. Paste it below.

Your token is stored only in this browser's localStorage and sent only to GitHub when you save edits. Sign-out: clear the site's data.
